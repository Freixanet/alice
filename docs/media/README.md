# README illustrations

`alice-iphone-hero.svg` and `alice-workflow.svg` are editable, self-contained
product illustrations created for this repository. They use the Alice wordmark,
simple geometry and system fonts, with no external images, tracking or scripts.
The matching PNG renders are used in the README for consistent rendering across
GitHub clients; keep the SVG sources when refreshing them. They contain no manga artwork, screenshots, personal data or third-party logos.

The illustrations describe stable product ideas rather than a release's screen
layout: a native iPhone companion, conversation, visible work and approvals.
Keep exact setup requirements and current limitations in the README text.

When the app changes:

- A new menu, color, icon, model or screen layout does not require new artwork.
- Revise the copy if these core workflows or the Hermes/iPhone relationship change.
- Keep the caption identifying the artwork as conceptual illustrations.
- Do not add fabricated screenshots, ratings, customer counts or success claims.
- Preserve SVG titles/descriptions and the README's image alt text.

Existing screenshots in this directory are historical documentation assets. They
are not the evergreen README artwork; check them against the current app before
using them in a release announcement.

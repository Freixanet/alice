# Reply to an assistant message on iPhone

Swipe an answered assistant message to the right. A haptic and return arrow indicate selection; other messages and the header blur while the selected message stays readable and the keyboard opens. Write your reply and send normally. Cancel the reply with the cross beside the recipient without losing your text.

The sent message displays the original quote and recipient above your answer. Reply selection survives changing chats and reopening an unsent draft. Quoted context goes to the current conversation's agent; it does not change routing. Older saved conversations remain readable.

Library contains Artifacts, Images and Notes; Notes no longer has a separate sidebar button.
